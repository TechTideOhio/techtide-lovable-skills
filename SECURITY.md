# Security Policy

Please do not disclose credentials, private prompts, customer data, production URLs, or vulnerability details in a public issue.

## Reporting

Use GitHub’s **private vulnerability reporting** for this repository when it is available. If that option is not available, contact the TechTide AI maintainers through the organization’s authenticated GitHub channels and provide the repository, affected package, impact, reproduction steps, and a safe mitigation if known.

Keep reports limited to the information needed to reproduce and assess the issue. Maintainers will determine the appropriate disclosure and remediation path.

## Scope

This policy covers the public skill packages, their import instructions, guardrails, and repository automation. Do not submit secrets or private workflow artifacts for debugging. For non-sensitive documentation or usage problems, use [`SUPPORT.md`](./SUPPORT.md) instead.
