# techtide-lovable-production-handoff

Single-skill Lovable package from [TechTide Harness Kit](https://github.com/TechTideOhio/techtide-harness-kit), published in the public [`techtide-lovable-skills`](https://github.com/TechTideOhio/techtide-lovable-skills) catalog.

Public source for this package:

```
https://github.com/TechTideOhio/techtide-lovable-skills/tree/main/techtide-lovable-production-handoff
```

To import it into Lovable, use this directory's `SKILL.md` (plus any `references/` files) with your workspace's skill-import flow. If you want Lovable's Settings, Skills, Import, GitHub flow, copy this directory to the root of a repository you control and import that repository's URL.

This directory intentionally contains one SKILL.md package so it can be imported without reading the full TechTide Harness Kit catalog.
