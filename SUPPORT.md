# Support

Use the channel that matches the nature of the request so maintainers can respond with the right context.

| Request | Path |
| --- | --- |
| Import or usage question | Open a public issue with the package name, import method, and expected versus observed behavior. |
| Documentation correction | Open an issue or pull request with the exact file and proposed wording. |
| New capability | Open a feature request describing the user problem, intended workflow, and alternatives considered. |
| Security vulnerability | Follow [`SECURITY.md`](./SECURITY.md); do not disclose sensitive details in a public issue. |
| Contribution | Read [`CONTRIBUTING.md`](./CONTRIBUTING.md) and include the smoke-test result. |

Please do not include credentials, private prompts, customer data, proprietary exports, or production-only URLs in issues or pull requests. For general organization routes, visit the [TechTide AI organization profile](https://github.com/TechTideOhio).
